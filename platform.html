// THE GATEWAY

A ROUTER THAT DECIDES.

Every incoming message passes through the LangGraph router. It classifies intent, picks the right agent, starts the right workflow — and hands the reply back through the same channel it arrived on.

router — message flow

[in] "INV-1044 pending, why?" ← whatsapp

[route] intent=reconciliation → fin.accounts

[workflow] match-invoice started

[guardrail] read-only query pass

[out] "Matched 47/47. INV-1044 flagged — freight mismatch ₹3,200. Approve adjustment?" → whatsapp

// WORKFLOWS

DEPARTMENT PROCESSES, AS GRAPHS.

Approval chains, onboarding, expense flows, compliance steps — define them as graphs per department. Start one from a chat message, an email, or a cron schedule. Human approvals pause the graph until someone taps.

START

TRIGGER

Chat, email, cron or webhook starts the workflow with a context payload.

$ workflow start --id onboarding

STEP

AUTO-CHAIN

Agents execute steps — generate, verify, fetch, format — advancing the graph.

$ step 2/5 complete

GATE

APPROVAL

Graph pauses. Approver gets notified on their channel with full context.

$ await approver

END

RESUME

Approve / reject / cancel — audited. Graph resumes or rolls back cleanly.

$ audit.log --tail

workflow — onboarding example

[trigger] $ workflow start --id onboarding --user ravi ← email

[step 1/5] generate offer letter done

[step 2/5] verify documents done

[gate] approval — offer above ₹12L → waiting for HR admin

[tap] approved → steps 3-5 auto-run

[end] onboarding pack emailed · audit logged
