FAQ

Questions, answered.

Does my data leave my server?

No. Babuba is self-hosted — the gateway, agents and database run on your machine. Your data never goes to our cloud. You can even run it air-gapped.

Which LLM does it use?

Bring your own — OpenAI, Anthropic, DeepSeek, Ollama, or any OpenAI-compatible endpoint. No lock-in; swap models per agent.

How long does deployment take?

About 15 minutes: install, connect channels, and the agents start learning your policies. Most teams run their first workflow the same day.

Can it read WhatsApp dispatch data?

Yes — that's a core workflow. Dispatch messages from multiple units are parsed into MIS rows and AFR lists automatically, with validation and exception flags.

What happens if the AI makes a mistake?

High-risk actions require your approval, every action is logged, and guardrails restrict what agents can do. You review — nothing ships without you.

Do I need a technical team?

No. The admin dashboard handles agents, channels, roles and workflows. If you can use a spreadsheet, you can run Babuba.
